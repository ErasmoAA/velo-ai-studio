# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public GitHub issue.

If the repository has GitHub private vulnerability reporting enabled, use that channel. Otherwise, contact the maintainer privately through the GitHub profile associated with this repository and include `Velo security report` in the subject or opening line.

Please provide:

- A clear description of the vulnerability.
- Steps or a minimal proof of concept to reproduce it.
- The affected file, feature, or workflow if known.
- The potential impact.
- Any suggested mitigation, if available.

Do not include passwords, API keys, access tokens, personal data, or other unrelated sensitive information in the report.

## Scope

This policy covers the Velo AI Studio source code and repository automation maintained in this repository.

Third-party services, browsers, operating systems, and dependencies may have their own security reporting processes and are outside the direct control of the project.

## Response

The maintainer will review credible reports, assess severity and impact, and work toward a fix before public disclosure when appropriate. Please allow reasonable time for investigation and remediation.
