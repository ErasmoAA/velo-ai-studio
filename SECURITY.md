# Security Policy

## Reporting a vulnerability

Please do not publish sensitive security details in a public GitHub issue.

For security concerns, contact the project maintainer through the contact information published at:

https://veloaistudio.online/contact.html

When reporting an issue, include enough information to reproduce the problem without including passwords, API keys, tokens, personal data, or other secrets.

## Secrets

Never commit API keys, access tokens, credentials, private keys, or `.env` files containing secrets. If a secret is accidentally exposed, rotate or revoke it immediately and report the incident through the private contact channel above.
